Chọn nhiều file .bytes
Có thể chọn hoặc kéo nhiều file vào đây. File trùng tên vẫn được giữ nguyên.
Thứ tự gộp: file 1 → file 2 → ... → file cuối
Tool giữ nguyên từng byte và nối dữ liệu chuẩn xác để game có thể đọc được.
Lưu ý mod skin: Dữ liệu nhị phân (.bytes) được nối tuần tự theo đúng cấu trúc byte gốc. Đảm bảo các file thành phần tương thích với cấu trúc mà game yêu cầu.
